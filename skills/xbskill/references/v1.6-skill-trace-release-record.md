## 本轮范围 / 排除项

范围：

1. 每个 xbskill 最终回答在结尾显示一个公开当前 Skill 的准确调用名。
2. Skill 名称后用日常语言说明本轮职责，作为用户可读的选择依据。
3. 简单问答也保留紧凑 Skill 轨迹；无跨会话价值时不追加保存提示。
4. 隐藏支持、内部维护专科、框架和下一步候选不成为第二署名。
5. 外测发现的 `$xb-decision` 最小试验披露、数据最小化、授权和校准门写入专科与回归测试。

排除项：

- 不新增公开 Skill 或菜单项。
- 不展示 G/H、八门、选择门等内部标签。
- 不把隐藏岗位知识支持显示成第二个当前 Skill。
- 不修改用户本地 `memory/`，不触碰 workspace 既有无关改动。
- 本轮不做 GitHub push/pull 或在线发布。
