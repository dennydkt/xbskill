2. 简单问答、纯教程、缺少材料后请求补充、澄清问题和预计分类为空均执行询问。
3. 同一最终回答仍在运行工具或继续分析时只报告中间进度，最终回答形成后再询问。
4. 用户决定前，导航记忆状态使用“待本次确认”或“待指定本地项目”。

## 失败与回写

1. v1.6 把简单问答判为低长期价值，并允许跳过询问。用户反馈证明该分支夺走了保存决定权。
2. 首轮修复使用“有实际内容”，独立评审发现该词仍可被自由解释；随后改为“至少一条用户消息＋最终回答交回控制权”。
3. 首轮陌生回答把缺材料后的等待状态判为连续执行；共享协议和边界表随后明确 B/C 分界。
4. 首轮 forward test 只检查摘要短语；终轮改为解析 A/B/C 冻结区段，直接验证 A/B 的保存问句和记忆状态，并验证 C 当前没有保存问句。
5. 八个已知跳过捷径短语进入活跃契约回归门；v1.6 旧证据保留原文，由本记录明确取代其运行预期。
