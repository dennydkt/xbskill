# 工作背景表单

第一次进入时说明用途。知道你负责什么、谁确认结果、手头有哪些材料后，XB 可以按实际分工给建议，或沿用你已有的模板。

每轮显示完成度和一张当前主题表。默认从本人开始，接着是公司、工作环境、文档。已给主题、材料或指定字段时从相应位置继续。按下表取当前仍可问的行，使用「想了解什么 / 回答例子 / 以后怎么用」三列，最多三行。用户可直接写、按编号答、跨组说、粘贴片段或上传文件，可只答一项。

## 完成度与下一问

固定 12 项。按表格行顺序记录稳定 ID：本人 `name, position, duties`，公司 `company, business, rules`，工作环境 `people, setup, changes`，文档 `types, sources, requirements`。复用本轮及获准的既有记录。每项按 ID 最多计一次，同一句话可以填多个明确回答的字段。例如“每周写周报”同时说明日常职责和常用文档，计入 duties 和 types；之后确认另一种文档时只补内容，types 仍计一次。明确“没有模板”或“独立工作，没有汇报人”可作有效答案。还未核对的材料、推断、过期、跳过或拒答均不计入已确认。收到新答案、改动或撤回后重新计算。

每次处理答复、附件、跳过、暂停或恢复时展示如“完成度 5/12 项（42%），跳过 1 项，待核对 2 项”。百分比按已确认项除以 12 四舍五入。只在用户需要时展开各项状态。背景完成度表示已有多少可用信息；任意进度均可用于当前工作。

用户可说“跳过这项”“先到这里”“继续工作背景”“只补文档”或“更新公司信息”。跳过当轮不再追问；用户主动选择该项才重开。明确拒答保持排除。按当前目标选择下一张表；所有未覆盖项均已跳过或拒答时结束该轮，保留真实完成度。尚可继续且用户愿意时，优先问会改变下一次帮助的主题。纠正或换岗后先核对受影响项，保留仍有效的答案。

## 材料和公司信息

收到附件先按 `document-intake.md` 读取可用范围，展示摘录与对应字段，保留待核对状态。附件不可读时说清文件与范围，继续接收文字。公司公开查询在用户明确要求或同意后按 `company-research.md` 执行；公开资料可补公司事实的来源，涉及用户在组织内的处境仍由用户核对。单纯补资料时沿用这张表；正式规则与实际做法的分析见 `../../xb-company/SKILL.md`。

## 暂停、退出和返回任务

用户说停止、先办事或明确拒绝继续时，立即停止展示问题。显示完成度和续接短语，已有任务直接恢复；背景只是当前对话记录时按实际范围说明。按已选保存提醒档位处理提示，保存授权单独取得。用户要求“保存后帮我做 X”时由 xb-save 按 `continuation.md` 写入，告知结果后继续 X；缺路径或保存失败也继续可安全执行的 X。明确拒绝保存后省去保存邀请。
