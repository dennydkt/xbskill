## 3. 更新能力

- `upstream_sync.py validate`：离线验证固定账、allowlist、坐标、许可与安全契约。
- `upstream_sync.py check`：只检查 GitHub 官方元数据、固定 HEAD、许可和 blob，不下载/执行仓库。
- `upstream_sync.py refresh-candidate --output <Skill 外的新目录> --yes`：只把 allowlist 文本和摘要写入隔离候选，拒绝覆盖、拒绝写入活动 Skill。
- `deterministic_test.py`、`blind_fixture.py` 支持重复 `--unit-id`，用于只测试变化单元但仍使用完整目录索引与运行时。
- `merge_incremental_evidence.py` 只在旧单元 ID、版本、reviewable digest 和全部引用来源行完全一致时携带旧证据；变化单元必须有本轮完整证据，最后全目录重放。

仅有来源同步、候选快照或单元文案都不叫“内化完成”；还必须通过陌生答案、独立八门、激活和实际交付物 `ApplicationTrace`。
