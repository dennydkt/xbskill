# 边界表达前的体验承接与逻辑复位

本协议服务于 `$xb-boundary`。用户已经被一句要求绕进委屈、内疚、自我怀疑、羞耻或“是不是我太敏感”的状态时，先帮助其恢复对事实、责任和选择的判断，再生成话术。

这里的“平复”指判断复位：用户能区分请求、义务、决定权、代价和拒绝后果，并看见至少一个安全选项。它属于非医疗的当下支持，不宣称情绪或健康已经恢复，也不用安慰提高用户对越界环境的忍耐。

## 触发与反例门

满足任一项进入本协议：

- 用户明确表达委屈、内疚、自责、羞耻、怕得罪、脑子乱或怀疑自己不够配合；
- 对方把个人或团队意愿直接写成用户义务，却省略职责、授权、容量和取舍；
- 对方把拒绝、追问或指出风险改写成忠诚、态度、能力、善良或合群问题；
- 决定权在对方，执行、错误、健康或关系代价持续落到用户；
- 临时例外被说成默认规则，或旧条件满足后又增加新的完成门；
- 判断藏在问句、大词或人格评价里，原任务、证据和决定人从讨论中消失。

以下情况关闭本协议或压缩到一句承接：明确职责内要求、预先存在的质量标准、证据与固定完成门齐全、补齐后可以复核；一次性低风险互助且用户能够自由接受或拒绝；用户只要一个简单句且当前材料没有委屈、自责、权力或安全信号。

## 安全覆盖

出现威胁、骚扰、报复、强制违规、即时安全风险、严重功能受损或持续羞辱时，先承接并降低对抗，再进入证据、现实支持和保护路径。普通拒绝话术可以推迟；公开指控、投诉、对质、辞职或外发仍由用户确认。

## 隐藏支持：逻辑复位包

命中强迫性话语结构时，完整读取 `../../xb-decode/references/workplace-discourse-defense.md`，只抽取与本次边界有关的最小结果：

```text
LogicResetPacket
逐字原话 / 用户转述：
仍待处理的原任务或决定：
可观察话语动作（最多 2 项）：
被改写的对象（请求/义务、决定/责任、受益/代价、拒绝/人格、例外/规则、进度/缺陷）：
权力—责任—成本变化：
正常要求的竞争解释：
会推翻当前识别的证据：
一句事实锚：
```

“强盗逻辑”可以作为用户描述体验的入口词。公开结论使用上述可观察结构；人物道德身份、恶意动机和心理标签不进入结果。

`$xb-boundary` 始终是唯一公开当前 Skill。该包属于隐藏支持，不触发 `$xb-decode` 的转出流程，不产生第二个 Skill 署名。

## 固定输出顺序

### 1. 承接具体体验

用一至两句回应用户已经给出的事件和感受，至少挂一项原话或事实。推荐结构：

> 你现在会感到【委屈/内疚/混乱】有现实原因：对方一边【可观察要求】，一边省略了【职责、容量、取舍、授权或代价】。

避免空泛乐观、“别想太多”、临床判断和劝忍。用户没有表达强烈感受时，只用一句指出压力来源即可。

### 2. 复位被改写的逻辑

从 `LogicResetPacket` 选择一至两项关键结构，用日常语言说明：

- 对方提出需求，不自动完成职责、授权和优先级确认；
- 团队目标需要明确任务取舍和成本承担者；
- 用户追问范围或拒绝超额承担，不自动构成态度、忠诚或能力问题；
- 有权决定优先级的人要承担取舍责任；执行者不单独吸收全部后果；
- 临时例外要写入口、期限和结束条件；
- 质量要求成立时回到既有标准、证据和固定完成门。

必须保留正常职责、表达笨拙、标准未共享或时间压力等竞争解释，并说明什么证据会让当前识别降级或撤回。

### 3. 恢复选择感

给一个短暂停顿点和两至三个现实选项，示例：

> 你先不用在“答应才算配合”的框架里证明自己。现在可以做的是：核对职责与现有任务、请有权者作取舍、给出条件性承担，或先留痕再决定是否升级。

这一步只恢复选择，不替用户决定对抗、投诉、离职或放弃权益。

### 4. 进入边界判断与话术

先给一个主话术，字段固定为：事实、当前范围、不能吸收的代价、可行替代、需要谁作什么取舍、确认时间。必要时再给“柔和 / 明确 / 留痕升级”两个相邻强度版本；高风险场景优先给保护动作和低暴露书面确认。

## 四个差分样本

### A 单方面加活并道德化

原话：“大家都这么忙，就你不能多担一点？团队意识呢？”用户说“我是不是太自私”。

合格处理：先承接内疚来源；识别大词遮蔽和决定权—责任错配；提醒团队协作仍需任务取舍；恢复“核对容量、条件性承担、请决定者排序”三个选项；最后给话术。不得把领导定性为强盗或操控者。

### B 正常质量复核

复核人引用上线清单第 7 项，指出证据缺失，承诺补齐后当天复核。用户觉得语气很冲。

合格处理：承接压力；明确职责、证据和固定完成门均存在，当前属于正常质量要求；语气与时限单独协商；给确认补件和复核时间的话术。不得套责任倒置或移动完成门。

### C 报复风险

用户拒绝违规要求后被移出项目群，考核标准被单独修改，并收到“再闹就让你走”的信息。

合格处理：先说明不安有明确事件来源；停止普通说服话术；保存原话、名单和考核版本，联系可信支持与有权渠道；任何投诉、公开对质或辞职动作仍由用户确认。

### D 一次性低风险互助

同事临时请用户帮忙打印两页材料，用户有空且可以自由拒绝。

合格处理：直接接受或简短拒绝；不运行强迫性逻辑识别，不增加长篇情绪承接和制度分析。

## 完成与回流

本轮最多声明“体验承接、逻辑复位和边界话术已交付”。用户是否平复，以其能否复述被改写的对象、看见至少一个安全选项为近端反馈；边界是否成立，以对方/有权者回应、现实执行、重复场景和用户负荷变化为反馈。

失败信号：用户读完更自责、更愤怒却说不出事实结构；话术仍默认用户吸收全部代价；正常质量要求被误判；高风险场景被推向正面对抗。出现任一项，回写触发门、竞争解释、措辞或安全覆盖，并重新外测。
