# 环境问题选择指南

问题是可调整的候选；每轮只取一行中的一题，按当前缺口排序。已知内容跳过；用户指定话题优先。选项可自由改写，不预选，不根据公司类别、城市或职级猜答案。开始没有任务时先问“你希望先从哪方面聊？日常工作 / 合作的人 / 公司做事方式 / 最近变化，也可自己说”。

| 域 | 候选问题与选项 | 对帮助的具体影响 | 辨别与边界 |
|---|---|---|---|
| 地点与工作方式 | 平常怎样和同事一起工作？同地办公 / 远程 / 混合 / 经常出差；也可自述或跳过 | 安排同步时段、书面协作、现场依赖 | 跨时区再问工作时区，涉及通勤再问大致城市和可接受耗时；精确地址无必要 |
| 职责与权限 | 当前这项工作你主要负责哪一环？提出需求 / 执行交付 / 审核验收 / 协调多人；可多选、自述或跳过 | 区分可直接做、应请示、需交接的行动 | 职称不能证明权限，必要时再单问谁能批准 |
| 人际与依赖 | 目前哪类合作最影响你把事做成？直属负责人 / 同组同事 / 跨部门 / 客户或外部伙伴；可自述或跳过 | 选下一段具体互动，识别决定、资源、验收关系 | 允许代号；一件事不能定人格，关系和权力变化带日期 |
| 公司规则 | 最近一件工作通常怎样拍板？明确负责人 / 多层审批 / 临时协商 / 还不清楚；可自述或跳过 | 分清正式流程、实际惯例、升级与留痕路径 | 下一问仅取一个近期例子，不从企业性质推导文化 |
| 近期变化与个人约束 | 最近最影响你工作的变化是哪类？岗位任务 / 领导团队 / 工作地点与节奏 / 暂无明显变化；可自述或跳过 | 刷新已失效背景，调整容量和可行做法 | 用户可另谈边界和偏好；不追问健康家庭财务，急事先做 |

有任务时优先问能区分两种安全行动的一题。例如“领导说要快”可能代表期限提前，也可能代表减少范围；先问哪一项有明确变动，避免把含糊评价记成稳定风格。

每域状态：unknown / pending / covered / skipped / declined / stale。covered只表示本轮已涉及，内容仍须带来源与适用范围。skipped可在用户主动回到该话题时重开；declined保持拒绝，只有用户明确重新愿意谈该域才重开。新变化只将相关已覆盖域标stale，拒答域继续保持declined。
