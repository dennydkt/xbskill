# xbskill 使用手册

> 本手册面向刚拿到 xbskill 的使用者与安装者。位置：`skills/xbskill/references/user-guide.md`。本文件缺失时，导航壳按 SKILL.md 的外部文件硬约定报错并停止手册模式，其他功能不受影响。

## 1. xbskill 是什么

xbskill（快点下班工作系统）是一套站在脑力工作者一侧的工作生存与选择系统，由 1 个唯一入口（`xbskill`）和 34 个专科（`xb-*`）组成，共 35 个公开 Skill，整体发布、整体安装。

它的北极星：帮助你在可接受的身心与伦理成本下完成必要结果，同时保留或增加理解、能力、边界和选择权。最大化产出本身没有作为目标。

你可以直接扔过来：

- 一个模糊任务：「帮我把这堆数据做成能汇报的图」
- 一段材料、一个难沟通的人：「领导总在会上否定我」
- 一项不会的软件操作
- 一件让你耗尽却推进不了的事

系统先判断你现在需要稳住、解卡、看懂、改变还是选择；再结合目标、状态、能力、相关同事和领导、公司环境，判断这件事应该解决、调整，还是停止、拒绝、升级、转岗或离开。

## 2. 安装

依赖按功能分层：通过 Skills CLI 安装需要 Node.js 22.20+；套件校验、`xb-save`、`xb-knowledge` 与 `xb-role-knowledge` 需要 Python 3.10+；其余纯文本专科没有 Python 或 Node.js 依赖。完整平台规则见 `runtime-compatibility.md`。

1. 将发布包里 `skills/` 下的 35 个目录作为完整套件复制到目标工具的 Skill 发现根（如 `.agents/skills/`、`.claude/skills/` 等）；`xbskill` 与所有 `xb-*` 必须保持同级。
2. 按平台解析 Python 3.10+，再在套件根目录运行校验：

   ```bash
   # macOS / Linux
   python3 -B skills/xbskill/scripts/suite_manager.py validate --target <目标 Skill 根>
   ```

   ```powershell
   # Windows PowerShell
   py -3 -B skills\xbskill\scripts\suite_manager.py validate --target <目标 Skill 根>
   ```

   出现 error 或 warning 时停止使用，先按报错修复（常见原因：套件复制不完整、目录被改名、混入了旧版本文件）。

3. 校验通过后，对目标工具说 `$xbskill` 或「新手入门」验证入口能被识别。

多工具共用：多个 AI 工具可以指向同一份套件（或各自复制一份）。会话记忆按项目路径存放（见第 5 节），与哪个工具无关。

## 3. 怎么开始用

四种等价的启动方式：

| 方式 | 示例 |
|------|------|
| 指令 | `$xbskill`、`/xbskill` |
| 口语 | 「快点下班」「无痛上班」 |
| 触发词 | 「上班问题」「工作卡住了」「帮我看看」「下一步怎么办」「新手入门」 |
| 最常用 | 直接把一件具体工作发过来，系统自动识别 |

你无需背诵任何专科名称。入口 Skill（`xbskill`）负责接住问题、定位当前瓶颈、调用一个专科、接收现实反馈并决定下一步；具体求解由 `xb-*` 专科完成。每轮结尾会提示本次调用的子技能。

## 4. 每轮你会看到什么

每个回答遵循「结论先行」：第一行就是结论本身。回答结尾按字段分行，例如：

> 调用子技能：$xb-decision
>
> 本轮：转岗与留下的初步对比
>
> 已交付：决策对比表
>
> 反馈点：本周五前找导师聊一次
>
> 记忆：当前未保存。若需要保存对话内容，请直接回复“保存对话”。

字段含义：

| 字段 | 含义 |
|------|------|
| 调用子技能 | 本轮唯一调用的专科名称 |
| 本轮 | 这轮解决或推进了什么 |
| 已交付 | 你拿到了什么产物 |
| 反馈点 | 下一步靠什么现实事件验证（期限、他人反馈、数据变化） |
| 记忆 | 本轮内容是否已保存、存在哪里；未落盘会写明原因 |

一次只推进一个瓶颈。下一步该做什么会根据上一轮结果动态判断，你只需对当前问题作出回应。

## 5. 记忆：记到哪、谁做主

- 记忆存放在**你的本地项目**：`<项目>/memory/xbskill/`，包含会话全文、摘要、分类账与进度档案。
- 每次会话收尾会在“记忆”项提示你回复“保存对话”；记与不记、何时停，都由你决定，不会静默写入。
- 回头使用时，开场会引用上次的主目标与反馈点（标注日期）；完整恢复走 `xb-restore`。
- xbskill 运行期的全部数据只在本地，不含账号、遥测或回传。通过上游 Skills CLI 安装时，按 `runtime-compatibility.md` 显式设置 `DISABLE_TELEMETRY=1`。

## 6. 专科速查

日常使用直接描述问题即可，路由自动完成。下表供你想主动点名某个专科时查阅。

**先判断大方向（五类信号）：**

| 你最需要的变化 | 常见候选 |
|----------------|----------|
| 稳住（负荷、边界、安全） | `xb-wellbeing`、`xb-boundary` |
| 解卡（推进具体任务） | 对应任务专科、`xb-action` |
| 看懂（问题出在哪） | `xb-triage`、`xb-analysis`、`xb-people`、`xb-company`、`xb-decode` |
| 改变（目标、计划、向上沟通） | `xb-goal`、`xb-plan`、`xb-upward`、`xb-stakeholder`、`xb-boundary` |
| 选择（继续、转岗、离开） | `xb-decision`、`xb-career` |

**任务与职能专科：**

| 场景 | 专科 |
|------|------|
| 需求模糊、完成标准不清 | `xb-goal` |
| 项目拆解、排期、依赖风险 | `xb-plan` |
| 邮件、方案、制度、说明文档 | `xb-writing` |
| PPT、述职、提案、答辩 | `xb-presentation` |
| 会前准备、主持、纪要 | `xb-meeting` |
| Excel/SQL/指标/图表/口径 | `xb-data` |
| 软件报错、权限、办公工具 | `xb-it` |
| 重复劳动、流程自动化、AI 工作流 | `xb-automation` |
| 周报、月报、阶段汇总 | `xb-report` |
| 学软件、补技能、上手新领域 | `xb-learning` |
| AI 原生能力发展与多周期编排 | `xb-ai-native` |
| 岗位专业知识的补充与修订 | `xb-role-knowledge` |

**人与组织专科：**

| 场景 | 专科 |
|------|------|
| 话里有话、听不懂领导的话 | `xb-decode` |
| 一句话怎么说、催进度、拒绝 | `xb-talk` |
| 向领导汇报、请示、管理预期 | `xb-upward` |
| 跨部门多方影响 | `xb-stakeholder` |
| 同事冲突、被甩锅 | `xb-conflict` |
| 理解自己/同事/领导的工作方式 | `xb-people` |
| 公司环境档案 | `xb-company` |

**自我与状态专科：**

| 场景 | 专科 |
|------|------|
| 明知要做却拖延、启动困难 | `xb-action` |
| 压力、耗竭、焦虑影响工作 | `xb-wellbeing` |
| 盘点能力、晋升差距 | `xb-capability` |
| 晋升、转岗、是否离职 | `xb-career` |
| 多方案取舍、要不要继续 | `xb-decision` |
| 说不清哪里有问题 | `xb-triage` |

**系统维护专科（需要时点名）：**

| 场景 | 专科 |
|------|------|
| 保存本次工作状态与会话全文 | `xb-save` |
| 接着上次继续 | `xb-restore` |
| 更新 xbskill 本身 | `xb-update` |
| 为新问题设计新专科 | `xb-builder` |
| 审查 xbskill 覆盖与安全 | `xb-audit` |
| 个人知识库与来源治理 | `xb-knowledge` |

五类岗位族（数据、产品研发、项目/行政、金融投研、营销）有纵深适配：路由时按需自动加载，无需手动指定。

## 7. 常见问题

**更新到新版本**：对 `xb-update` 说「更新 xbskill」，它会先备份、预览差异再更新，可回滚。手动更新前先备份目标根，`LOCAL-*` 文件会被保留。

**引用文件缺失报错**：套件要求所有文件位于 `skills/xbskill/references/` 等固定相对位置。报错信息会给出缺失路径；补齐文件或重新完整复制套件，禁止只用部分目录运行。

**适合谁**：被任务、沟通、选择、状态任一环节卡住的脑力工作者；覆盖数据、产品研发、项目/行政、金融投研、营销五类岗位族纵深。它提供工作相关支持，不做临床诊断；出现安全风险时优先保护，再谈效率。

**一句话总结**：把最近最想处理的一件工作直接发过来，说得乱也可以；每轮结尾看分行收尾信息，保存与否你做主。
