# 环境与运行交付

## 识别真正使用软件的电脑

把 `execution_host`（Agent 所在机器）和 `target_device`（用户实际使用的设备）分别记录。远程容器、云沙盒或 CI 的探测只证明执行主机条件。已有可信设备信息就使用；无法判断且会影响交付时问一个关键问题，不要求用户回答已探测的参数。

目标环境最少记录：OS/版本与架构、实际启动习惯、联网/离线、安装与管理员权限、是否给同事使用。按任务补充 Python/Node/浏览器、Office/WPS、输入规模、可写目录和文件关联。未知项明确写“未知”，不要推定存在。

可由 Agent 在获准电脑运行随包只读脚本 `../scripts/probe_environment.py`（相对于本文件）。需要已有 Python 3 才可运行；无 Python 时使用宿主提供的只读设备工具或向用户确认，不能为探测擅自安装运行时。

```text
<PYTHON3> <xb-it绝对路径>/scripts/probe_environment.py --scope execution-host
```

只有确认命令确实在用户实际电脑执行时才能使用 `--scope user-device --confirmed-local`。脚本只检查可发现性；网络、安装许可、Office 兼容和应用实际可用性仍需独立核对。给用户的界面不展示探测 JSON 或要求复制命令，Agent 能执行时直接执行。

## 形式选择

| 条件 | 优先评估的形式 | 交付前必须证明 |
|---|---|---|
| 浏览器即可完成、离线轻量处理、无安装权限 | 自包含 HTML/静态文件包 | 双击 `file://` 实际完成任务；全部依赖本地；文件读取/下载和所需格式已验证 |
| 需要成熟数据处理库、模板生成或较复杂逻辑 | 便携本地网页工具 | 运行时/依赖随包或目标机已验证；单入口启动、回环绑定、健康检查后开浏览器、端口冲突与关闭行为 |
| 频繁选文件/批处理、希望桌面窗口 | 原生或轻量桌面应用 | 目标平台的可执行程序、窗口响应、文件选择、进度/异常、实际导出结果 |
| 用户现有环境已配齐且接受脚本 | 项目隔离运行时与启动脚本 | 启动器完成路径/依赖检查；从双击入口验证；缺依赖有明确处理办法 |
| 主要在 Excel 内使用、企业允许相关扩展 | 工作簿/宏/插件 | 实际 Office/WPS 与格式兼容、宏策略及授权、保留公式/格式要求 |

用户明确要桌面程序就按目标继续；若约束阻止实现，说明具体原因并给替代形式供其决定。避免默认所有工作都做网站或所有桌面应用都用重型框架。

单文件 HTML 只在浏览器能够完成全部确认功能时采用；多表、公式/格式保真、大文件或特殊算法应先验证能力。将 XLSX 改成 CSV、删除公式、依赖 CDN、要求联网或更换平台均可能改变确认范围，不能静默转换。

## 构建与依赖

- 工程内隔离依赖并锁定版本；能复用项目依赖时按已有工程执行。打包包含实际使用的库、模板、模型与资源，检查体积，避免把作者开发环境全部打包。
- 需要下载安装依赖时区分构建机与使用者电脑；按当前授权和网络条件处理。断网交付包含必要依赖或选择真正自包含形式，禁止启动时悄悄下载。
- 启动脚本以自身位置解析资源，正确处理中文与空格路径；报错停留可读，日志写入可写位置并避免包含业务原文或密钥。禁止把用户带到命令行研究依赖。
- Windows EXE、macOS app、Linux 包分别构建和验证。Windows 构建成功只证明该构建；无目标系统运行证据时标为待验证。系统提示按可信分发/签名方式处理，禁止要求关闭安全控制。
- 本地网页默认监听 `127.0.0.1`；需要局域网/公网共享时单独评估授权、认证与数据暴露。后台启动在可用平台上使用隐藏窗口；需要用户操作的主界面保持可见。

## 实际入口验收

在与工程目录分开的新目录解压最终包，用接收者将使用的入口启动；尽可能使用不同账户、干净虚拟机或独立执行者，明确记录所用方式及局限。测试数据使用合成或获准脱敏样本。

1. 未配置开发环境时，实际入口能启动；若声明依赖已安装，校验版本和路径是否成立。
2. 正常任务完整执行，生成的文件重新打开并按验收规则核对。
3. 一个关键错误样本显示原因和恢复动作；失败不覆盖原件，也不留下冒充成功的结果。
4. 再运行一次，确认历史输出/版本处理符合约定；更换工作目录或中文空格路径仍可启动。
5. 打包产物与源码基线对同样输入给出相同业务结果；有意变化逐项记录。

有浏览器/桌面工具时实际点击，不用阅读 HTML/代码代替界面实测；缺 UI 操作能力时可测后端和入口进程，但界面验收明确保留待验证。启动了进程但窗口或结果不可见，只记该项观察。

交付记录写明构建与实测平台、入口、样本、预期/实际、结果路径和包 SHA-256。未能验证目标机时，交付构建产物并标“目标机首次运行待验证”；给一条具体验证路径，禁止泛称“任何电脑立即可用”。

## 公开合成场景

- 表格工具：文件选择 → 表头/格式校验 → 处理 → 结果预览 → 新文件导出；编码前导零、空行、重复和文件占用作为边界。
- 周报工具：选择统计周期与输入/模板 → 核对时间覆盖 → 生成 → 校验计算和排版 → 输出新目录；自动发给他人另按权限执行。
- 商品清洗：保留原值和顺序，展示建议值、规则与待复核状态；未识别项仍有结果记录。匹配库缺失时显式停止相关计算，禁止返回零分或空值假装正常。

样例描述工作方式，不附任何公司的数据、路径、品牌清单或隐含业务口径。
