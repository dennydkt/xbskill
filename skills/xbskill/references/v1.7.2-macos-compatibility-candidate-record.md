## 修复范围

- 新增 `runtime-compatibility.md`，固定 Windows、macOS 与 Linux 的 Python 3.10+ 解析、Node.js 22.20+ 前提、Skills CLI 遥测开关、路径和 LF 约束。
- `xb-save`、`xb-knowledge`、`xb-role-knowledge` 与知识来源协议统一使用 `<PYTHON3>`，由平台契约解析启动命令。
- 公开发布模板增加 `macos-latest` 与 `ubuntu-latest`、Python 3.10 与 3.12 的交叉矩阵，并执行本地 Skills CLI 安装冒烟。
- 公开安装文档分别给出 macOS/Linux 与 Windows PowerShell 命令，声明脚本型功能的 Python 依赖和安装器的 Node.js 依赖。
- `skills/**` 固定为 UTF-8、LF，发布治理拒绝 CR、NUL 与缺失的跨平台标记。

## 验收边界

本地候选必须通过套件校验、陌生接收方回归、隐藏维护边界、角色知识回归、公开包治理和兼容副本零差异。GitHub macOS runner 结果要在候选进入远端 CI 后单独记录。Codex、Claude Code 等桌面宿主的发现与交互结论保留到真实 Mac 实测。

任一 macOS CI 单元失败时，候选保持未发布状态，并按失败命令、平台、Python 版本和日志坐标回写。本记录不把 Windows 本机结果换算成真实 Mac 通过。
