# 思想镜头：可检验判断能力

本文件把已故思想家的部分方法操作化为工作判断镜头。人物只标示方法来源，不是回答角色、人格模板或正确性担保。这里的表述是 `xbskill` 的工作化改写，不是人物原话或完整思想体系。

## 强制使用协议

1. 先按专科流程确认问题、事实和风险，再从下列镜头中选择；不得因为熟悉某位人物而反向套题。
2. 每个用户问题最多使用 1–2 个镜头。若第三个镜头才会改变动作，留到现实结果回流后的下一轮。
3. 对所选镜头必须形成完整链条：`触发证据 → 观察 → 辨别动作 → 产物字段 → 推翻条件`。只有人物名、概念名或感想不算使用。
4. 镜头结论的强度不得超过用户材料和一手证据。来源人物不能替代事实、数据、授权、伦理判断或用户选择。
5. 禁止第一人称模拟人物，禁止伪造或拼接名言，禁止用“某某会怎么想”装饰答案。
6. 若镜头的不适用边界被触发，停止该镜头并按安全、法律、医疗、权限或对应专科边界处理，不得静默降级。

## 选择速查

| 当前判断瓶颈 | 优先候选镜头 |
|---|---|
| 同一个词各说各话、目标措辞漂移 | 维特根斯坦 |
| 目的与手段倒置、具体处境中的取舍 | 亚里士多德 |
| 结论无法被现实纠正 | 波普尔 |
| 争论太久但缺少低成本现实反馈 | 杜威 |
| 信息、时间和选项有限，迟迟无法停止搜索 | 赫伯特·西蒙 |
| 冲突被压服或平均妥协，未处理真实利益 | 玛丽·帕克·福列特 |
| “按角色执行”掩盖授权、责任或强制 | 阿伦特 |
| 超载、受压和注意力受损被归因为个人能力 | 西蒙娜·薇依 |
| 单次失误与系统性波动混淆 | 戴明 |
| 正式制度与实际规则不同，边界、监测、申诉缺位 | 奥斯特罗姆 |

## 1. 维特根斯坦：概念用法镜头

- **触发**：争议围绕“专业、尽快、支持、负责、完成、高质量”等词；同一词在不同人、场景或阶段指向不同验收动作；目标变化可能只是措辞未变而用法已变。
- **观察**：谁在什么场景使用该词；哪些实际案例被算作符合或不符合；该词改变了谁的行动、验收或责任；正式定义与实际用法是否一致。
- **辨别动作**：建立“用法对照”：保留原词，收集一个被接受的正例和一个被拒绝的反例，写出两者可观察差异；把暂定含义改写成行为、产物或阈值，并请有决定权者校准。
- **写入产物字段**：`原词`、`使用者/场景`、`被接受正例`、`被拒绝反例`、`可观察差异`、`暂定操作定义`、`定义来源`、`有效期/重审触发`。
- **推翻条件**：新案例无法按暂定差异分类；有权验收者明确给出不同用法；同一用法在关键场景持续产生相反判断。出现任一项就撤回操作定义并重做对照。
- **不适用边界**：不要把数据真假、因果关系、安全红线或权力压制化约成“只是语言问题”；正式法规、合同或技术标准存在时优先核对原文。
- **来源人物及生卒年**：路德维希·维特根斯坦（Ludwig Wittgenstein，1889–1951）。

## 2. 亚里士多德：目的—手段与实践判断镜头

- **触发**：动作清单替代了结果；手段被当成不可质疑的目的；多个合理目标在具体处境中冲突；目标或条件变化后仍机械执行旧计划。
- **观察**：最终希望发生的变化、当前交付、采用的手段、谁获得收益与承担代价；不可通约的现实约束；谁有权在此情境中作取舍。
- **辨别动作**：画“目的—阶段结果—手段”链，逐项追问“为了什么”和“若有更低成本手段是否仍必须如此”；列出情境约束与实际代价，由有权者对具体取舍作判断，而非寻找脱离情境的万能规则。
- **写入产物字段**：`最终目的`、`阶段结果`、`当前手段`、`受益者/承担者`、`情境约束`、`取舍理由`、`决定人`、`重新判断触发`。
- **推翻条件**：用户不接受该目的；手段与目的没有可说明的因果联系；关键条件变化使原取舍不再成立；新的可行手段以更低代价达到同一结果。
- **不适用边界**：不替用户定义“善”或人生目的；不以抽象德性替代事实核验、专业规范、法律要求或组织授权。
- **来源人物及生卒年**：亚里士多德（Aristotle，公元前 384–前 322）。

## 3. 波普尔：反证与翻转条件镜头

- **触发**：观点能解释任何结果；分析只收集支持材料；计划、能力判断或人物画像没有“什么证据会让我改口”；AI 生成内容被当成掌握证据。
- **观察**：结论预言了什么可观察结果；什么结果与它冲突；替代解释是否给出不同预测；证据是否独立于结论产生。
- **辨别动作**：把结论改写为“若 X 成立，在条件 C 下应看到 Y”；事先写明反例、阈值与观察窗口；优先寻找最能区分首选解释和替代解释的证据。
- **写入产物字段**：`待检验主张`、`适用条件`、`预测`、`反证/阈值`、`替代解释`、`验证材料`、`观察窗口`、`翻转后的动作`。
- **推翻条件**：预先声明的反证出现；关键预测重复失败；没有任何可能观察能改变主张。最后一种情况应把它改列为价值偏好、定义或不可检验叙述，而非继续称为事实判断。
- **不适用边界**：价值选择、尊严底线和不可逆高风险决策不能仅靠反证实验处理；缺乏安全试验条件时提高证据门槛，不拿用户冒险。
- **来源人物及生卒年**：卡尔·波普尔（Karl Popper，1902–1994）。

## 4. 杜威：最小探究实验镜头

- **触发**：问题长期停留在抽象争论；原因不明但存在可逆的小范围动作；学习、流程或协作假设需要现实反馈。
- **观察**：造成困扰的具体情境、当前基线、可控制变量、反馈周期、可观察结果、试验失败的损失和回滚条件。
- **辨别动作**：把争论改写成一次最小探究：只改变一个主要变量，记录基线，写下预期结果，在短窗口内执行并观察；依据结果修改问题定义或下一动作。
- **写入产物字段**：`问题情境`、`当前基线`、`暂定假设`、`单一改动`、`时间/样本`、`观察指标`、`停止/回滚条件`、`现实结果`、`更新后的判断`。
- **推翻条件**：改动没有产生预测差异；结果受未控制变量主导；试验代价、风险或不可逆性超过信息价值。前两项推翻当前假设，后一项推翻本试验方案。
- **不适用边界**：不在医疗、法律、人身安全、生产权限或重大不可逆事项上擅自试验；没有授权时只能设计或模拟，不能执行。
- **来源人物及生卒年**：约翰·杜威（John Dewey，1859–1952）。

## 5. 赫伯特·西蒙：有限理性与满意化镜头

- **触发**：信息、时间、注意力或算力有限；选项搜索没有尽头；计划超载；用户需要一个足够好且能按时行动的方案。
- **观察**：硬约束、最低可接受标准、搜索新信息的成本、可比较选项数量、决策截止时间、错误代价和可逆性。
- **辨别动作**：先写硬门槛与满意阈值，再规定搜索顺序、时间/选项预算和停止规则；找到首个过门槛方案时停止，除非新增信息的预期价值高于等待成本。
- **写入产物字段**：`硬约束`、`满意阈值`、`搜索范围`、`信息预算`、`停止规则`、`首个合格方案`、`未满足风险`、`复盘日期`。
- **推翻条件**：所选方案未过硬门槛；关键约束或错误代价改变；继续搜索的预期收益明显高于延迟成本；出现支配当前选项的新方案。
- **不适用边界**：安全、伦理、合规和不可逆高风险事项不能因“够用”而降低硬门槛；满意化不是草率或为超载常态化背书。
- **来源人物及生卒年**：赫伯特·A·西蒙（Herbert A. Simon，1916–2001）。

## 6. 玛丽·帕克·福列特：共同权力与整合冲突镜头

- **触发**：冲突只有压服或各退一步两种方案；一方以职位控制另一方；跨团队在立场上对撞但可能存在可整合利益。
- **观察**：各方公开立场、背后利益、控制的资源、承担的风险、权力差、共同问题、可共同创造而非分配的变量，以及低权力方是否能安全表达。
- **辨别动作**：把“谁赢”改写为共同问题，分别列立场与利益；辨认当前是 `power-over`（支配）还是 `power-with`（共同形成行动能力）；寻找同时满足核心利益的新安排，并写明未被整合的剩余成本。
- **写入产物字段**：`参与方`、`权力/资源`、`表面立场`、`核心利益`、`共同问题`、`支配风险`、`整合方案`、`剩余损失`、`同意/升级条件`。
- **推翻条件**：一方可惩罚另一方且没有安全表达或申诉渠道；所谓共同利益不能抵消核心权利冲突；整合方案实施后仍单向转嫁成本。此时停止协作优化，转边界或升级。
- **不适用边界**：骚扰、威胁、报复、违法和不可协商的尊严/安全底线不是“双方冲突”；不要求低权力方用更好沟通换取基本保护。
- **来源人物及生卒年**：玛丽·帕克·福列特（Mary Parker Follett，1868–1933）。

## 7. 阿伦特：角色—责任—强制镜头

- **触发**：“我只是执行”“系统要求的”“领导让我做”被用来结束责任判断；授权、执行、知情和后果承担混在一起；组织角色可能遮蔽个人仍保有的选择。
- **观察**：正式指令、授权链、当事人知道什么、拥有多大裁量、可预见影响、拒绝/质疑/升级渠道、实际强制与报复风险。
- **辨别动作**：建立角色—责任账：拆开提出、决定、授权、执行、复核和承担后果的人；区分合法权威、组织惯例、同侪服从与现实强制；标出不能随角色转移的专业、伦理和事实报告责任。
- **写入产物字段**：`角色`、`收到的指令`、`授权来源`、`知情范围`、`实际裁量`、`可预见影响`、`责任归属`、`异议/升级渠道`、`强制证据`、`最小负责动作`。
- **推翻条件**：新证据改变了授权链、知情程度或实际裁量；原以为可拒绝但存在可信报复风险；原以为被强制但实际存在安全替代渠道。随证据重分责任与动作，不固化道德标签。
- **不适用边界**：不做法律责任认定，不把结构性强制简化成个人勇气问题，不要求用户进行高风险的英雄式反抗。
- **来源人物及生卒年**：汉娜·阿伦特（Hannah Arendt，1906–1975）。

## 8. 西蒙娜·薇依：注意、受压与容量镜头

- **触发**：超载、持续打断、受压、麻木、反复低级错误或无法思考被直接归因为懒惰、态度或能力；用户的节奏和注意力长期被外部控制。
- **观察**：任务量与时限、切换和打断、睡眠/休息等当前容量事实、注意能够连续维持多久、权力压力、错误随负荷如何变化、是否有减负和求助空间。
- **辨别动作**：做容量账而非人格判断：计算当前可用注意单元与外部要求，定位一个最伤注意的压力源；先减少、延后、合并或隔离一项负荷，再观察错误和启动是否变化。
- **写入产物字段**：`容量事实`、`压力来源`、`注意单元`、`打断/切换`、`任务要求`、`可调整负荷`、`恢复条件`、`安全支持`、`红线/升级信号`。
- **推翻条件**：容量恢复且压力下降后，同类断点仍稳定出现；错误与负荷变化无关；新证据显示主要是知识、流程或权限缺口。此时转能力或系统假设。
- **不适用边界**：不做临床诊断或治疗；出现严重失能、自伤风险、持续躯体症状或医疗问题时，优先专业支持与安全安排。
- **来源人物及生卒年**：西蒙娜·薇依（Simone Weil，1909–1943）。

## 9. 戴明：共同原因与特殊原因镜头

- **触发**：一次失误就归咎个人；同类问题跨人员、跨周期反复；绩效、缺陷、超载或延期存在波动，但不知道该改人还是改系统。
- **观察**：结果的操作定义、时间序列或跨人分布、稳定基线、近期过程变更、仅影响个别事件的异常、工作量与资源配置。
- **辨别动作**：先收集足以看分布的同口径样本，再区分共同原因与特殊原因：多人/多期随过程稳定出现，优先查系统；单次偏离且有可追踪独特事件，先局部处置。用改变后的分布验证归因。
- **写入产物字段**：`结果定义`、`样本范围`、`基线/分布`、`共同原因候选`、`特殊事件`、`归因置信度`、`过程改动`、`局部处置`、`验证窗口`、`分布变化`。
- **推翻条件**：过程改动后模式不变；扩大样本后问题集中于可追踪的个别事件；所谓特殊事件在多人多期重复出现。出现这些证据就交换或重开归因。
- **不适用边界**：样本不足时只能给暂定归因，不能伪造统计确定性；安全事故先控制伤害，不能等完整分布后再行动；系统原因不抹去可证实的个人责任。
- **来源人物及生卒年**：W·爱德华兹·戴明（W. Edwards Deming，1900–1993）。

## 10. 奥斯特罗姆：实际规则与治理镜头

- **触发**：正式制度与实际运行不同；共享资料、预算、排期、晋升名额或协作资源缺少清晰边界；维护、监测、申诉和改规则的权利不明。
- **观察**：参与者与资源边界、谁可进入和受益、日常真正遵循的 `rules-in-use`、谁监测、违规如何处理、争议去哪申诉、谁能修改规则及其成本。
- **辨别动作**：画最小制度图：参与者、资源、正式规则、实际规则、决定权、信息、收益/成本、监测、分级处置、申诉和改规则渠道；用近期真实案例验证，不以制度文本自动代表现实。
- **写入产物字段**：`参与者/边界`、`共享资源`、`正式规则`、`实际规则`、`决定权`、`监测者/证据`、`分级处置`、`申诉渠道`、`改规则权`、`案例日期`、`冲突/缺口`。
- **推翻条件**：连续真实决策与所写实际规则不符；参与者或资源边界改变；申诉、监测或改规则渠道只是纸面存在；问题并非共享治理而是单一授权关系。出现任一项就更新制度图或换镜头。
- **不适用边界**：不假设所有组织都允许自治；高权力差、报复或违法情境先保护用户；不把描述实际规则等同认可其正当性。
- **来源人物及生卒年**：埃莉诺·奥斯特罗姆（Elinor Ostrom，1933–2012）。

## 输出最小格式

使用镜头时至少在专科产物中留下：

```text
所选镜头（最多 2 个）：
触发证据：
观察与来源：
辨别动作：
写入的专科字段：
当前判断与置信度：
失败/推翻信号：
不适用边界或未用镜头：
```

镜头没有产生新观察、具体动作、产物字段或推翻条件时，删除人物名，回到专科原流程。
