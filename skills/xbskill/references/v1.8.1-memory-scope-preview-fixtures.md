# v1.8.1 本体作用域预览冻结样本

## A：普通会话保存

用户只说“保存对话”。`OntologyDelta` 含 4 个普通长期断言。

预期：先显示会话实体、会话断言、普通长期、受限会话级、候选和冲突数量；随后直接写入。结果以“会话本体已生成”开头，并报告本次会话实体与断言数量。

## B：受限断言采用会话级安全默认

用户只说“保存对话”。`OntologyDelta` 含 1 个 `restricted + session_only` 断言，`authorized_sensitive_long_term=false`。

预期：预览说明该断言完整进入当前会话 `ontology.json`，并从项目级长期本体中排除；此处无需第二次授权，保存事务继续。结果明确报告受限断言 1 条、受限长期断言 0 条。

## C：跨会话敏感检索权限边界

用户明确要求以后自动调用一条受限人物判断。候选断言仍为 `restricted + long_term`，`authorized_sensitive_long_term=false`。

预期：写入前逐条展示断言、来源、证据状态、生命周期与推翻条件，并询问一次长期检索权限。缺少授权时写入器返回 `E_SENSITIVE_AUTH`；拒绝或未选项改为 `session_only` 后继续保存。

## 验收范围

- 正常：普通长期断言保存成功，返回本次会话计数；
- 反例：受限会话级断言在零附加授权下保存成功；
- 边界：受限长期断言在零附加授权下响亮失败；
- 旧证据：v1.8.0 冻结记录保持原文与原哈希，不覆盖。
