# DBS → XB 专科白盒重写方法

## 目的

本方法用于把 DBS 中有效的 Skill 工程机制转化为 XB 的职场专科，而不是把“创业、内容、流量”等词替换成“上班、任务、同事”。它既是 `xb-builder` 的建设规程，也是 `xb-audit` 的专科内容验收门。

XB 的运行不依赖 DBS 文件存在。DBS 只作为设计期研究样本；所有进入 XB 的判断都必须在 XB 的目标函数、职场事实、权限结构、安全边界和案例中重新成立。外部发布前若来源权利不明确，只做功能重实现，不逐字复制领域资产、案例、作者声音或公式库。

## 先判迁移对象

把一个候选文本单元写成：

```text
U = <任务目的, 成功定义, 因果先验, 证据, 行动者/权限,
     干预, 风险, 路由, 产物, 案例, 完成与回流>
```

逐字段做三分，而不是全段“保留/删除”：

| 处置 | 可以进入什么 | 典型内容 | 必须留下的说明 |
|---|---|---|---|
| 保留 Keep | 与领域无关的程序不变量 | 显式 I/O、单步路由、状态机、事实/推断分账、证伪、回流、版本治理 | 为什么不依赖自媒体/商业语境 |
| 重写 Re-derive | 机制可用但语义依赖领域 | 诊断变量、因果模型、信号、阈值、权限、话术、产物字段、案例、完成指标 | XB 新假设、依据、适用边界和翻转条件 |
| 拒绝 Reject | 在职场中无证据、越权或有害 | 固定心理归因、伪精确比例、利润唯一、操纵话术、忽略雇佣权力、攻击性人格 | 拒绝理由及它会造成的具体误判 |

只更换命名空间、路径、命令名和无语义导航文案，才允许词句级替换。只要候选内容会改变“为什么、做什么、谁来做、风险由谁承担或怎样算完成”，最小改写单位就不是一句话，而是下面的完整证据闭环。

## 安全的最小重写单元

每个专科判断至少包含八个相连器官：

1. **触发与适用边界**：什么可观察信号进入本专科；什么信号必须转给相邻专科或安全边界。
2. **专科模型**：本专科真正操作的对象、成功定义和条件性因果关系。模型不得用人格标签或作者确信代替事实。
3. **观察与竞争解释**：需要哪些字段；至少保留一个会导向不同动作的替代解释。事实、用户解释、AI 推断、未知分账。
4. **辨别动作**：用一个低成本且有信息增益的问题、材料核验、对照或可逆试验区分候选；不是继续堆观点。
5. **分支与阈值**：证据落在哪个分支；谁有决定权；哪些安全、容量、权限或不可逆性条件覆盖普通流程。
6. **动作与产物**：交付可直接使用的内容，写清必填字段、执行者、验收者、成本和用户保留的决定。
7. **正例、反例与边界例**：正例说明怎样完整运行；反例暴露最可能的误判；边界例说明何时停止本方法。
8. **现实验证与更新**：事先写观察窗口、成功/失败信号、翻转后的动作和完成范围；产物存在不等于现实问题改变。

阈值不能只写一个看似可测的数字。任何错误率、成功率、采用率、时长或净收益门都要同时写明单位/分母、代表性样本或窗口、基线及波动、错误后果、依据来源、决定/批准者和重估条件；证据不足时只能标“待校准”，不得用伪精确数字授权扩大风险。来源内容同样分“可访问、可引用、可复制/再利用、可提交/传播”：公开可访问或如实标注，不自动补齐许可、个人信息/保密、公司规则和使用授权。

任何器官改变，都要检查下游器官是否随之失效。例如把执行阻力的公理从“拖延源于逃避”改为“保护性阻力、容量、目标、能力、工具、风险均是候选”，则信号词典、分支、实验、案例、完成指标必须一起重写。

## XB 的领域重推导

### 1. 目标函数

所有专科先服从同一个北极星：在可接受的身心、伦理和机会成本下完成必要结果，同时保留或增加理解、能力、边界和选择权。不能只证明雇主产出增加；还要检查用户净收益。

### 2. 工作问题的候选因果面

观察到一个症状时，不直接选根因。按任务所需从下列因果面形成竞争解释：

- **目标/任务**：对象、版本、标准、优先级、依赖和验收是否清楚；
- **状态/容量**：时间、注意、睡眠、安全、控制和基本功能是否足以执行；
- **能力**：在相似情境中是否有稳定产物和异常处理证据；
- **工具/信息**：访问、数据、版本、系统行为和专科知识是否可靠；
- **人物/关系**：信息、承诺、利益、工作方式和一次具体互动发生了什么；
- **权力/权限**：谁提出、决定、授权、执行、复核和承担后果；是否有强制或报复；
- **公司/制度**：正式规则、实际规则、激励、资源、申诉和改规则通道如何运行；
- **价值/选择**：目标是否值得解决，还是更应调整、拒绝、暂停、升级、转岗或退出。

没有跨期、跨人或事件证据时，只能给暂定归因和区分动作。系统原因不抹去可证实的个人责任；个人事件也不能抹去稳定的结构模式。

### 3. 任务专科的四重完成

IT、数据、自动化、写作、汇报等任务不能只检查“生成了东西”。至少区分：

1. **正确**：事实、计算、格式、运行或语义符合标准；
2. **有用**：它回答真实目标并让目标受众能行动；
3. **被采用**：有权者或使用者在现实流程中接受、运行或据此决定；
4. **净收益为正**：复核、错误、维护、培训、权限和风险成本没有吞掉节省。

本轮最多只能声明已有证据支持的层级。模板、草稿、测试方案和沙盒通过不能冒充现实采用或净收益。

### 4. 人物与组织专科的四分法

协作问题先拆成：

- **个人事件**：一次可观察行为、信息或承诺；
- **关系机制**：双方预期、依赖、权力和重复互动；
- **流程问题**：接口、版本、标准、资源和责任闭环；
- **制度环境**：正式/实际规则、激励、监测、申诉和报复风险。

情绪和用户解释是重要材料，但不是自动事实。所谓“沟通技巧”不能替代基本保护、权责裁决或制度修复。

## 专科运行模板

专科不必逐字展示所有字段，但内部必须能回答：

```text
任务与成功定义：
适用 / 不适用：
已知事实、用户解释、推断、未知：
首选解释与至少一个替代解释：
最有信息增益的辨别动作：
当前分支、权限与风险闸：
本轮直接产物：
用户保留的决定/责任：
正例 / 反例 / 边界例：
现实观察窗口与指标：
失败或翻转条件：
完成范围与下一反馈点：
```

若一个简单任务的关键字段都已给出，直接产出，不为填满模板盘问用户。只有缺口会改变动作、风险或验收时才追问；最多问最有区分力的问题。

### 岗位纵深附加门

当专科服务具体岗位时，再检查：

```text
实际角色与责任帽子：
当前任务族 / 生命周期位置：
S0/S1/S2 的任务证据（不是年限/职级）：
上游 / 下游 / 决定 owner / 验收 owner：
岗位特有产物、异常与越权边界：
组织类别候选 / 已证实组织基因 / 反例：
解法因阶段和组织证据发生的具体差异：
```

岗位知识只有同时改变观察项、判断、行动、产物或现实反馈之一才算内化。只添加术语、工具清单、职责百科或岗位名称属于内容增厚，不得计为纵深。公司类别直接生成文化结论、岗位阶段由工龄换算、或三套岗位图谱无差别加载，均为拒绝项。

岗位知识单元还必须生成可机验作用轨迹：`unit_id@version → claim/evidence → effect_id → 实际交付物 SHA-256/逐字片段 → 本轮改变的动作与具体产物字段 → 验证点 → 现实反馈点`。验证必须读取实际交付物；只读了、引用了、显示了单元名称或填写未来计划属于惰性知识，报 `E_RK_INERT`。S0/S1/S2 只能改变讲解粒度、分支复杂度和用户保留动作，不能复制出三套专业事实。

## 建设顺序

1. 冻结两个以上差异样本和原始输出，至少包含一个反例或高风险边界。
2. 画候选 Skill 的器官图，逐项标 Keep / Re-derive / Reject；记录来源位置，但运行产物不依赖来源包。
3. 先写 XB 专科模型、用户侧成功定义和不适用边界，再写信号与流程。
4. 把竞争解释、辨别动作、权限、风险、产物字段、案例和翻转条件同步补齐。
5. 用专科自己的原则审计自己：要求用户显形的证据、忽略、假设和完成范围，Skill 本身也必须显形。
6. 把所有“有意忽略”改成用户可见的省略及理由；无法显形的静默忽略是拒绝项。
7. 保持渐进披露：`SKILL.md` 放运行协议；长字典、模板和跨专科模式放一层 `references/`；个人/公司内容只进经授权的项目上下文。
8. 在干净接收环境由未参与设计的回答者按字面首次使用；答案冻结后交给另一名评审，设计者不得补脑。
9. 失败进入流程、字段、示例或自动测试；不能只写一条“以后注意”的教训。
10. 岗位纵深版本用 `role-specialty-regression.md` 做角色×阶段×组织反刻板盲测；回答者与评审者分离，冻结答案后再评分。

## 八门验收

每门 0–2 分：0 为缺失/有害，1 为部分具备或依赖作者补脑，2 为陌生执行者可按字面完成并验证。

| 门 | 2 分要求 |
|---|---|
| G 目标适配 | 成功定义服务 XB 用户侧北极星，目标层级和完成范围清楚 |
| C 因果有效 | 有条件性模型、竞争解释和会改变动作的辨别证据 |
| A 行动权限 | 提出、决定、授权、执行、复核、承担者分清，不把帮助能级当权限 |
| P 权力/结构 | 能区分个人、关系、流程、制度，不把结构伤害心理化 |
| S 安全边界 | 健康、隐私、合规、报复和不可逆风险有停止/升级条件 |
| E 证据证伪 | 字段、来源、置信度、反例、翻转条件和观察窗口完整 |
| R 现实结果 | 产物、当前干预和现实 Problem 分开，并有反馈回流 |
| V 陌生外测 | 干净会话可首次使用；缺依赖响亮失败；独立评审无补脑 |

任一门为 0，拒绝上线；任一门为 1，只能留在重写区。八门全为 2 才可称完整专科。高总分不能抵消安全、权限、权力或现实完成门的 0 分。

## 迁移追踪最小记录

```text
候选来源与位置：
保留的程序机制：
重写的领域语义：
拒绝的先验/资产及原因：
XB 新假设与依据：
会推翻它的证据：
新增正/反/边界样本：
陌生回答者记录：
独立评分与修订：
```

这份记录用于建设和审计，不要求在普通用户答案中展示。真正的验收不是“文字变厚”，而是陌生用户面对真实职场问题时，能获得更准确的归因、更有权限意识的动作、更可用的产物和可回流的现实证据。
