# xbskill v1.0 岗位知识发布记录

## 发布结论

- 发布对象：`xb-role-knowledge` 内置目录 2.0.0。
- 发布状态：15/15 单元为 `active`，覆盖 `data / product_rd / function / finance / marketing` 五类岗位族。
- 本轮变化：产品经理、UX 两个单元修订；金融投研、营销两个单元新增；其余 11 个单元经摘要、来源行和旧证据逐项一致后复用。
- 运行边界：普通任务仍只有一个当前 `xb-*` 专科；`xb-role-knowledge` 只返回最小 `RoleKnowledgePacket`。每个 active 回答都明确保留 `execution_authorized=false`，包形成不代表现实问题已解决。

## 失败没有被覆盖

Round10 使用新的题集、新回答者和新的独立评审者。没有修改 Round9 答案，也没有把旧失败计为本轮通过证据。

## 上游与安全边界

- 活动功能来源：UI/UX、产品、金融投研和营销仓库均固定到 40 位 commit、allowlist、行坐标、许可和只读安全策略。
- 每个上游 `affected_units` 必须命中当前活动目录中的真实单元 ID；校验器和 11 项 mocked self-test 会拒绝把来源漂移路由到不存在的候选名。
- Dean Peters 与 VoltAgent 只作 `discovery_only`，不能支撑 active claim。
- `K-Dense-AI/claude-admin-skills` 仍为 `expected_unavailable`，没有用同名仓库或模型记忆替代。
- GitHub API 的真实在线检查此前遇到 403 限流后已响亮停止；本次发布只使用已冻结的提交和内容摘要，没有重新抓取，也没有执行任何上游代码。

## 现实边界与用户复核点

本记录只证明岗位知识能被当前专科匹配、进入实际交付物并由 Trace 复核，不证明任何组织已经采纳建议，也不授权交易、付款、发布、生产变更或接受剩余风险。

用户可主动抽查：

1. `builtin-role-knowledge.json` 是否为 15 个 active 单元，并绑定本记录中的 evidence/source 摘要。
2. `role-knowledge-regression.json` 中任取一个 Round10 active case，核对 answer、artifact SHA、专业 effect、六权、风险门、阶段适配、`execution_authorized=false` 与独立评审是否同链。
3. `upstream-role-sources.json` 中 Dean/Volt/K-Dense 的用途和不可用边界是否仍未被扩大。
