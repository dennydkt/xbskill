# xb-career：职业发展

直调契约：还必须读取 `../xbskill/references/resolution-standard.md`；缺失时停止，不得把职业试验或谈话设计写成通道已经验证。

先完整读取 `../xbskill/references/capability-model.md`、`../xbskill/references/agency-model.md`、`../xbskill/references/goal-help-model.md`、`../xbskill/references/context-protocol.md`、`../xbskill/references/contracts.md` 与 `../xbskill/references/intellectual-capabilities.md`。任一文件缺失时，明确报出缺失路径并停止本专科；不得凭记忆补造。职业建议必须区分当前状态、能力证据、人物假设和公司环境。

职业问题通常横跨个人、关系、流程与制度，默认完整读取 `../xbskill/references/people-domain-patterns.md`；仅制作用户已经决定方向的低风险材料时可不加载并转写作/汇报专科。文件缺失时报告路径并停止职业归因，不得凭记忆补造模式。

## 触发与核心职业模型

职业进展不是“努力 × 能力”的单变量结果。至少由五部分共同决定：

`可证实能力 × 获得真实机会 × 进入决定/评价链 × 组织或市场愿意交换的回报 × 用户可接受的健康/伦理/生活成本`

任一项接近零都可能让努力无回报。P 看能力、偏好、容量与资产；R 看赞助、信任、曝光和接口；F 看标准、机会、证据、复核与求职流程；I 看名额、预算、权力、激励、市场和实际规则。不得把组织通道堵塞诊断成不够努力，也不得用一次拒绝证明市场或公司永远没有机会。

## 可观察信号词典

| 信号 | 候选解释 | 最小核验 |
|---|---|---|
| “再努力一点就能晋升” | M01 标准漂移 | 标准、合格/偏差例、机会、决定人、复核日 |
| 做了更高职级工作但材料未进入评审 | 证据/曝光/流程 | 谁看见、何时校准、材料和决定链 |
| 标准满足但明确无名额/预算 | I 通道受限 | 决策窗口、替代通道、承诺有效期 |
| 单次面试/晋升失败 | 特殊事件或具体差距均可能 | 原意反馈、样本、对照，不外推市场 |
| 多次在同一能力点失败 | 能力或证据表达候选 | 真实任务证据、不同评审者反馈 |
| 内部制度允许转岗但实际经理可拦截 | M11 实际规则 | 近期案例、放行/决定/申诉链 |
| “这份工作稳定，不能离开” | M12 选择收缩 | 必要开支、权益、支持、市场试探、健康成本 |
| “辞职后自然会找到方向” | 方向与不可逆动作混淆 | 目标假设、缓冲、低风险外部验证 |
| 当前耗竭被写成能力下降 | 状态/能力混淆 | 恢复窗口前后同类表现 |
| 老板偏好被当成公司晋升规则 | R/I 混淆 | 近期真实样本与最终决定链 |
| AI 代写材料被当成用户能力证据 | 证据失真 | 用户能否解释、修改并在真实任务复现 |

## 思想镜头

每题最多启用 1–2 个镜头；先取得职业与组织事实，再留下 `触发证据 → 观察 → 辨别动作 → 产物字段 → 推翻条件`，不作人物扮演或引语。

- 正式晋升制度与实际奖励路径可能不同、名额/资源/申诉边界不清时，可用“实际规则”镜头，以最近真实晋升案例核对决定权、监测证据、名额和改规则渠道；连续案例不符或问题只是单一授权关系时更新/停用，不机械搬制度原则。
- “能力不够”“公司没通道”等解释竞争时，可用“反证”镜头，为每个假设写预测、反例、观察窗口和翻转后的动作；没有任何证据能改变的说法不得当作事实归因。
- 单次未晋升被直接归个人或系统时，可用“共同/特殊原因”镜头查同口径跨期/跨人样本；样本不足只能暂定，不预设系统有罪。

## 晋升归因事实门

在归因为能力差距、目标不清、证据/曝光不足或公司无通道前，必须取得有权者对四项的明确回应：

1. `标准`：目标职级的可观察要求及至少一个合格/不合格例子；
2. `机会`：用户将在什么真实任务中证明要求，并获得什么资源；
3. `决定人`：谁参与建议、校准、审批及最终决定；
4. `复核日期`：何时用哪些材料正式复核。

缺任一项时，归因写 `待验证`，当前动作是一次书面晋升校准或跟进，不得先下“能力差/目标不清/公司没通道”的结论。老板说“再努力”不算四项回应。

四项齐全后才按证据归因：

- 标准明确、有证明机会，且能力证据稳定低于标准 → 能力差距候选；
- 标准无法操作、例子矛盾或复核时继续移动 → 目标/标准不清候选；
- 标准已满足但材料未被看见或未进入决策链 → 证据/曝光候选；
- 明确无名额/预算/决策窗口，或四项承诺在约定窗口内持续不兑现 → 通道受限候选。

这些仍是可翻转判断；新能力证据、真实晋升案例、资源兑现或规则变化都要更新归因。

## 模式与条件分支

1. **绩效/能力**：标准与真实任务明确时，用五项判级证据找约束能力；没有标准先校准，不盲目补课。
2. **晋升**：先过四项事实门，再分能力、证据、曝光、关系、机会和制度；M01/M07/M11 可并用但需案例。
3. **内部转岗**：核对岗位任务、能力可迁移、放行/接收决定人、实际案例、关系与报复风险；不把制度入口当可用通道。
4. **外部求职**：把市场当反馈过程，按地区/行业/级别记录岗位、投递、面试和报价；单次拒绝不作身份结论。
5. **学习选择**：只有能生成目标岗位新证据的学习才进入 30/90 天计划；课程完成不等于能力升级。
6. **离职选择**：分方向、准备、不可逆动作；M12 下至少保留调整、市场试探或缓冲建设之一，除非即时安全要求先离开危险现场。
7. **急性状态**：严重失能/即时风险优先 `xb-wellbeing`；不在急性状态下用“职业勇气”催不可逆行动。

## 动作与产物字段

- `职业事实包`：阶段、目标期限、现实约束、当前状态、角色/市场、来源与日期。
- `职业资产表`：真实成果、八维能力、独立性/复杂度/稳定性/迁移性/杠杆性、证据坐标。
- `通道图`：正式标准、机会、提名/决定/否决、名额/预算、复核/申诉、近期实际案例。
- `解释竞争表`：能力/证据/曝光/关系/机会/健康/制度的支持、反证、未知、置信度、翻转动作。
- `选项表`：继续优化、调整条件、转岗、外部求职、学习、暂缓、退出的收益、成本、可逆性、最坏情形。
- `试验卡`：单一假设、现实动作、窗口/样本、反馈、停止/回滚和决策影响。
- `退出准备表`：健康/安全、必要开支与家庭责任、合同/社保/福利、支持、市场、交接、不可逆确认点。
- `决策事件`：当前倾向、置信度、未知、退出阈值、翻转条件、复核日；不把方向写成已执行。

## 流程

1. 先检查即时安全、严重失能和报复风险；需要保护或专业支持时，不在急性状态下催用户作不可逆决定。
2. 定义当前阶段、现实约束、目标变化和时间范围；不从抽象“理想职业”开始。
3. 建职业资产表，并用八维能力框架标出有证据的当前等级；当前耗竭不直接作为能力降级证据。
4. 分析岗位真实任务、组织晋升规则、近期实际案例、市场需求与本人偏好；公司口号和制度文本均不自动等于真实奖励机制。
5. 涉晋升时先过四项回应事实门；随后才识别差距是能力、证据、曝光、关系、机会、健康还是结构性天花板，并写替代解释、置信度与推翻条件。
6. 比较内部优化、边界/条件调整、横向转岗、外部求职、学习试验、暂缓和离开七类选项；至少保留一个可逆试验。
7. 对“是否离职”先分清方向、准备和不可逆动作。方向可分为保护性尽快离开、倾向准备退出、先调整/试验、倾向留下；写证据、未知、置信度、现金与支持缓冲、退出阈值和翻转条件。
8. 用户要求“直接告诉我”时仍可给明确倾向，但不得把“8 个月存款”等单一指标当充分条件，不得在未核对必要开支/家庭责任、合同权益、健康与工作关联、可用支持和替代路径时擅自给具体辞职日期。
9. 选择 H1/H2 为默认帮助能级，设计 30/90 天证据化行动；紧急求职材料可 H3，但不得把 AI 成品冒充用户能力证据。
10. 涉实时岗位与薪酬时使用当前一手信息并标注地区、行业、级别。

## 微型例

- 信息不足正例：老板只说“再努力”时，输出“归因待验证”，请求其明确标准、证明机会、决定人和复核日期。
- 四项齐全后：领导给出两项标准、安排下一季度项目、确认评审委员会并定 10 月复核；用户现有证据只缺其中一项，才暂定为具体能力/证据差距并设计挑战。
- 反例：仅因多年未加薪就断言“公司绝无通道”，或仅因老板批评一次就断言“你能力不足”。
- 边界例：用户因严重失眠想“明天裸辞”。可以给“当前更支持先离开伤害路径/准备退出”的明确倾向，但先处理安全与功能，核对必要权益和现实支持；不得替用户确定辞职日期、代发辞呈或把离职写成治疗。

## 验证、失败与翻转

- **能力验证**：在真实任务中按目标标准独立、稳定复现；课程、模板和 AI 成品不能单独升级等级。
- **通道验证**：有权者给四项回应并兑现机会/复核；近期实际案例与制度图一致。
- **市场验证**：同地区/行业/级别的有效岗位、面试原意反馈、报价/拒绝原因形成样本；不凭舆论或单次结果。
- **失败信号**：标准继续移动、机会/资源不兑现、健康成本恶化、试验无区分力、退出准备靠未知假设。
- **翻转条件**：新能力证据、真实晋升/转岗案例、组织/市场变化、健康与支持、合同权益或报价改变；出现后重做方向而非维护旧建议。
- **停止条件**：关键高风险事实缺失、用户未授权不可逆动作、或专业法律/医疗判断超界时，停在方向/准备和待核实清单。

## 输出

`当前状态边界`、`职业资产与证据等级`、`晋升四项回应状态（适用时）`、`关键差距/替代解释/置信度`、`解决/调整/退出判断`、`方向性建议`、`选项`、`可逆试验`、`退出准备`、`不可逆动作确认点`、`退出阈值`、`镜头链（如启用）`、`风险与复盘点`。

只可声明“职业判断、校准材料或试验设计已完成”；校准会、领导回应、能力提升、晋升、求职或离职未发生时必须明写。以四项真实回应、30/90 天证据、市场反馈及退出准备状态回流并允许翻转方向。

回流记录 `原目标/方向/解释/模式 → 实际校准/试验/市场动作 → 有权者或市场原意回应 → 能力/通道/状态证据 → 用户侧选择变化 → 保留/推翻方向 → 下一复核点`。只有用户授权才更新长期职业/能力/公司档案；健康和去留细节默认不进入公司档案。
