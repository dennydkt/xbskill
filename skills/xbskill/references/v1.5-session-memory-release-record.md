## 本轮范围 / 排除项

范围：

1. 每个真实任务在收尾检查点显示一次明确保存问句；用户继续对话后有新内容，下个收尾点再次提示。
2. 当前会话逐次授权；旧 `auto_checkpoint` 字段不能授权全文或分类写入。
3. 用户同意后保存可见对话、会话摘要、分类账和滚动进度到 `<project>/memory/xbskill/`。
4. 自动分类覆盖自己、性格与说话风格、领导、同事、关系、公司/公司调性、目标、项目进展、决定和工作事件。
5. 用户陈述、可观察事件、助手推断和用户决定分层；单次事件与指代不明项留候选。
6. 新增事务写入器，执行本地路径约束、当前会话授权、完整性、凭据模式、路径穿越、同会话增量与写后重读门。

排除项：

- 不保存系统/开发者提示、隐藏推理和工具底层日志。
- 不把敏感对话自动固化为长期人物或公司画像。
- 不执行云同步、Git 提交、外发、删除或批量迁移。
- 不声称历史压缩后仍可恢复缺失的逐字消息。

## 正常、反例与边界样本

| 样本 | 输入/条件 | 预期与实测 |
|---|---|---|
| 正常：本地保存 | 用户当轮同意；两轮可见对话；一条个人表达偏好 | 写出 transcript/session/classification/progress，并将候选写入 `context/people/self.md`；通过 |
| 正常：会话增量 | 同一 session ID 再次保存 | 更新原会话与同一上下文块，零重复块；通过 |
| 反例：无当轮授权 | `authorized_current_session=false` | `E_AUTHORIZATION`，零写入；通过 |
| 反例：路径穿越 | `context/../../escape.md` | `E_PATH`，零越界写入；通过 |
| 反例：凭据模式 | transcript 含私钥头 | `E_SECRET`，要求先排除；通过 |
| 边界：历史有缺口 | `complete` 同时声明缺失轮次 | `E_COMPLETENESS`，禁止标完整；通过 |
| 边界：项目未知 | 收尾时无法确定项目根 | 保存提示要求“保存到 <本地项目路径>”；静态锚与依赖缺失测试通过 |
| 边界：旧自动设置 | `auto_checkpoint: on` | 仍需当前会话同意；静态锚通过 |
