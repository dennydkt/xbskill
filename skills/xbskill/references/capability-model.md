# 上班族能力框架

## 定义

能力 = 在一类真实工作情境中，以一定独立性和稳定性，处理相应复杂度并产出可验收结果。知识、偏好、人格、潜力和一次高光都不等于能力。

## 八类能力

| 能力 | 能做成什么 | 主要证据 | 关联 Skill |
|---|---|---|---|
| 1. 目标定界 | 把模糊输入变成目标、范围与验收 | 需求书、目标声明、返工率 | `xb-goal` |
| 2. 分析判断 | 用事实拆解、解释、取舍并证伪 | 分析稿、决策记录、预测结果 | `xb-analysis`、`xb-decision`、`xb-data` |
| 3. 计划执行 | 把目标变成责任、依赖、节奏和结果 | 计划、里程碑、按期交付、异常处理 | `xb-plan`、`xb-action` |
| 4. 数字与工具 | 用软件、数据和自动化提高质量与杠杆 | 文件、查询、脚本、自动化运行证据 | `xb-it`、`xb-data`、`xb-automation` |
| 5. 表达交付 | 让不同受众理解、决策和行动 | 邮件、文档、PPT、报告与采纳结果 | `xb-writing`、`xb-presentation`、`xb-report` |
| 6. 协作影响 | 与人交换信息、资源与承诺并处理冲突 | 会议决定、协作结果、反馈、冲突记录 | `xb-meeting`、`xb-talk`、`xb-stakeholder`、`xb-conflict` |
| 7. 组织导航 | 理解权责、领导逻辑、公司激励与边界 | 资源争取、升级、跨部门落地、风险控制 | `xb-upward`、`xb-boundary`、`xb-company` |
| 8. 自我续航 | 管理注意力、压力、学习、职业和知识资产 | 稳定表现、学习迁移、复用资产、恢复记录 | `xb-wellbeing`、`xb-learning`、`xb-career`、`xb-knowledge` |

## 五个能力等级

| 等级 | 行为标准 | 不能据此升级的假象 |
|---|---|---|
| L0 依赖 | 需要他人逐步指令、检查和纠错才能完成 | 知道概念、看过教程 |
| L1 标准执行 | 能按明确流程完成常规任务，遇变体需要帮助 | 偶尔独立完成一次 |
| L2 独立交付 | 能自己定步骤、处理常见异常并稳定交付 | 只在熟悉环境表现好 |
| L3 复杂求解 | 能处理模糊、跨域和高风险问题，优化流程并指导他人 | 职级高、表达自信 |
| L4 组织杠杆 | 能建立标准、系统和人才机制，让多人持续产出 | 个人英雄式救火 |

等级不是身份。一个人可在 Excel 为 L3、冲突处理为 L1；同一能力在不同公司环境也可能表现不同。

## 岗位任务阶段与 L0–L4 的关系

`role-context-model.md` 使用 S0 新手/探路、S1 入门/独立常规、S2 老手/复杂系统化来决定**本轮怎样帮助**；L0–L4 描述一项能力在特定任务族中的**长期证据**。两者相关但不能机械换算：

| 任务阶段 | 常见但非强制的能力区间 | 判定依据 | 不能据此贴标签 |
|---|---|---|---|
| S0 新手/探路 | 常见 L0–L1 | 对该任务/环境尚无稳定闭环，需要样例、停手点或复核 | 工龄短、刚入职、用户自称新手 |
| S1 入门/独立常规 | 常见 L1–L2 | 能独立完成常规闭环并处理常见变体 | 做过一次、能使用某工具、拿到证书 |
| S2 老手/复杂系统化 | 常见 L2–L4 | 能稳定处理复杂/高风险问题，并产生迁移或组织杠杆 | 职级高、年限长、表达自信、个人救火 |

资深者进入新行业、新系统、新法规或新权责环境时可暂用 S0/S1 帮助；这不降低其其他任务族的能力。反之，新人能完成一次高质量任务也不自动获得 S2 或 L3/L4。

岗位纵深判级先建立“角色—任务族证据卡”：

```text
实际角色与责任：
任务族 / 生命周期位置：
代表产物：
现实使用或结果：
独立性 / 异常处理：
跨时间稳定性 / 换情境迁移：
是否形成他人可用的标准或机制：
环境条件、权限与反证：
当前 S 阶段（仅用于帮助） / 当前 L 证据：
```

数据、产品研发和职能任务族分别从 `data-work-specialties.md`、`product-rd-specialties.md`、`function-work-specialties.md` 选择。岗位图谱提供观察项和挑战样本，不提供自动分数；不能用岗位名或技术栈清单代替真实证据。

## 五项判级证据

1. **独立性**：需要多少指令、检查和救援？
2. **复杂度**：能处理多少模糊、变化、依赖和风险？
3. **稳定性**：能否跨时间重复，而非一次高光？
4. **迁移性**：换对象、工具或情境后还能否做成？
5. **杠杆性**：只提高个人产出，还是能形成流程、标准和他人能力？

五项证据不一致时，说明分项差异，不强行取平均。目标等级由真实目标角色和公司要求决定。

## 发展顺序

先找当前目标的约束性能力，再设计能生成新证据的工作挑战。默认不做八维平均补短；不以课程完成、证书或 AI 代做结果直接升级能力等级。
