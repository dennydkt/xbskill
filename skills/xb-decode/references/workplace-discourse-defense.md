# 职场话语动作与发声防御

本文件处理一类公开可见的问题：一句话表面上在讨论工作，实际改变了议题、举证责任、评价边界、决定条件或责任归属。目标是帮助用户复位事实、保护具体的人和修复决定链，同时避免给说话者定性或猜测动机。

## 1. 先做四组分账

| 容易混在一起的对象 | 必须拆开的判断 |
|---|---|
| 有权表达 / 表达正确 / 表达合宜 / 有权决定 | 能发言只说明可以进入讨论；内容仍要接受事实、标准、责任与权限检查 |
| 问句形式 / 问句完成的动作 / 举证责任 | 问号可能表达好奇，也可能暗含否定；判断式问句仍要给依据和可翻转条件 |
| 工作公开 / 接受质量评价 / 同意人格羞辱 | 公开交付允许相关评审；评价范围受目标、职责、标准、隐私和尊严约束 |
| 可观察行为 / 可能动机 / 稳定身份 | 先处理原话和影响；动机只列候选，身份标签不进入报告 |

任何一组没有拆开，先暂停“他是什么人”的判断，回到原话、标准、决定与影响。

## 2. 进入本分支的信号

满足任一项即可检查话语动作：

- 工作事实或风险尚未得到回应，讨论转向发言人的资历、态度、忠诚、动机或性格；
- 对方用“大家都这样、顾全大局、赶进度”等抽象目标覆盖一个可核验的具体风险；
- 一句带判断的问话没有依据，却要求被问者证明自己无错；
- 交付仍在过程阶段，局部未完成被写成永久缺陷或能力结论；
- 评价标准在用户满足后继续移动，且新的完成条件没有提前显形；
- 发言权被偷换成内容免检，公开参与被偷换成接受羞辱，个人偏好被偷换成他人义务；
- 提出风险的人被写成“制造问题的人”，原风险和决定责任从记录中消失。

以下情况优先按正常质量讨论处理：评价者有明确职责；指向事先存在的标准或证据；给出可达到的完成条件；补齐后愿意复核；评价聚焦工作对象。语气生硬可以单独调整，不能据此完成恶意定性。

## 3. 八类常见话语动作

标签只帮助定位动作，不能替代逐字证据。

| 动作 | 可观察结构 | 决定链风险 | 最小复位 |
|---|---|---|---|
| 资格换轨 | 用资历、职位或经历替代对命题的回应 | 正确风险因身份低被排除 | 请先核对命题与证据，资格另议 |
| 动机换轨 | 猜“你只是想出风头/找事” | 不可证伪动机压过可核验内容 | 先处理内容；动机判断需要独立证据 |
| 大词遮蔽 | 用大局、效率、团结等词覆盖具体条件 | 抽象目标免于成本和风险检查 | 写清大词对应的决定、代价和 owner |
| 判断藏进问句 | 用“这也能用？”表达否定却不承担依据 | 举证负担全部推给被问者 | 请把判断、依据和通过条件说完整 |
| 进度写成缺陷 | 把尚未做到写成永久缺失或能力问题 | 过程被提前验收，声誉受损 | 区分当前进度、计划范围和最终验收 |
| 评价权扩张 | 从“我可以评论”跳到“我的评论无需约束” | 人格、隐私和无关领域被纳入评审 | 评价回到职责、目标、标准和证据 |
| 责任倒置 | 把受影响者的发声写成冲突来源 | 原行为和决定责任离开记录 | 同时记录原行为、影响、提出者和决定者 |
| 移动完成门 | 旧条件满足后临时增加新条件 | 对方无法完成，评价长期悬空 | 固定当前版本、验收 owner 与变更记录 |

## 4. 六步复位链

### 第一步：冻结原题

记录逐字原话、此前讨论的工作命题、当时需要作出的决定、在场者和渠道。用户转述时标记为转述；没有原句就不做词句级定性。

### 第二步：拆命题与动作

分别回答：

1. 这句话提供了什么可核验主张或证据？
2. 它把注意力、举证责任、评价边界或责任归属移到了哪里？

如果内容足以直接解决原题，按普通质量讨论处理；若原题仍悬空，再进入动作诊断。

### 第三步：检查权责与影响

写清谁提出主张、谁提供证据、谁决定、谁执行、谁复核、谁承担错误后果。再确认话语动作是否改变了以下任一项：

- 一个风险能否进入决定记录；
- 某人的专业意见能否被听见；
- 评价是否越过工作对象进入人格或身份；
- 旁观者是否会把未证实评价当成既定事实；
- 后续追责时能否找到当时的命题、证据和决定 owner。

### 第四步：保留竞争解释

至少列一个能导向不同动作的解释，例如：表达笨拙、职责误解、时间压力、证据不足、质量标准未共享、稳定压制或报复。每个解释写一个可观察的翻转信号。

可用的低成本辨别动作：请对方补判断依据和通过条件；把原题写回会议纪要；询问验收 owner 是否认可当前标准；观察补齐证据后评价是否停止移动。

### 第五步：选择发声目标

一次只选一个主目标：

1. **复位事实**：让原命题回到证据和决定链；
2. **保护具体的人**：限制人格、动机和无关资格评价；
3. **修复公共记录**：让旁观者看到风险、版本、责任和待决项；
4. **启动保护**：出现羞辱、歧视、骚扰、威胁或报复信号时留痕并转 `xb-boundary`。

发声对象可以是原发言者、决定 owner、主持人、记录人或旁观者。选对对象优先于争赢一轮辩论。

### 第六步：按权力与风险定级

| 级别 | 条件 | 回应方向 |
|---|---|---|
| L0 低利害 | 平级、一次、可逆、无声誉或决定影响 | 澄清原题，邀请补依据 |
| L1 决定受影响 | 评价会改变验收、资源、责任或公共记录 | 当场复位事实，写入标准、owner 和决定时间 |
| L2 人身与持续压制 | 公开贬低、反复无关评价、权力落差明显 | 降低正面对抗，保存原话和记录，寻找主持人/支持者/正式渠道 |
| L3 威胁与报复 | 移出信息流、单独改考核、歧视骚扰、惩罚性威胁 | 停止普通解码，先转 `xb-boundary`；安全、证据和现实支持优先 |

## 5. 交付模板

```text
原题与待决事项：
逐字证据 / 用户转述：
可核验内容：
话语动作及其证据：
被改变的举证、权限、评价边界或责任：
对决定、当事人和旁观者的影响：
竞争解释与翻转信号：
本轮发声目标与对象：
回应方向（复位事实 / 保护具体的人 / 修复记录 / 启动保护）：
风险级别与停止条件：
下一现实反馈点：
```

完整成稿继续交给 `xb-talk` 或 `xb-upward`。本专科至少交付一条“事实锚”：不攻击身份，能把讨论拉回原题、证据、标准或决定 owner。

## 6. 三个差分样本

### 正例：资格压过口径风险

年轻同事指出退款口径可能重复计算，另一人回应其资历、态度和“问题太多”，没有核对口径。报告应冻结口径风险，识别资格换轨与大词遮蔽，建议主持人把风险、验证人和决定时间写入记录。事实锚示例：

> 先把退款是否重复计算核对完；资历评价不能替代这条口径的验证结果。

### 反例：有权复核人的明确追问

复核人引用既有验收清单，指出退款验证结果缺失，并说明补齐后复核。报告应判为质量追问；其职责、证据和完成门均可核对。若语气造成压力，只处理表达与会议方式。

### 边界例：公开羞辱后出现报复信号

主管持续公开侮辱同一员工；员工举证后被移出项目群、考核标准被单独修改并收到威胁。立即保存原话、时间线、名单和考核版本，转 `xb-boundary`。后续分析不能延迟保护动作。

## 7. 现实验证与翻转

本轮报告完成只表示用户拿到可使用的识别与发声方案。团队讨论、评价记录和当事人处境是否改善，要在以下信号回来后判断：

- 原题是否回到证据和 owner；
- 会议纪要是否保留风险与决定；
- 人格或动机评价是否停止；
- 补齐证据后完成门是否稳定；
- 发声者是否遭遇信息、资源、考核或关系上的不利变化。

出现新事实能证明评价有明确职责、证据和固定完成门时，撤回“压制性话语动作”判断。出现威胁、报复、歧视、骚扰或持续羞辱时，升级保护，不继续以沟通技巧消化结构风险。
